# 银龄核查助手

面向老年人的谣言与诈骗核查智能体。子女或社区网格员把长辈收到的一条可疑消息转发进来
（文字、截图或语音），系统给出风险等级、结论、可追溯的权威出处，以及一句能让老人听懂的转述。

> 参赛项目：第十一届华为 ICT 大赛 · 创新赛 · 赛题二
> （基于华为云 AgentArts 智能体开发平台打造 Agent）

## 它特殊在哪

市面上的辟谣工具和通用大模型问答，都在回答"真的假的"。这个项目回答的是另一组问题：

- **依据在哪**：结论必须携带可追溯的原文，等级分「官方原文 / 平台辟谣 / 媒体报道」三级
- **查不到怎么办**：明确回答"暂时查不到官方说法"，而不是让模型猜一个
- **谁在查**：发起核查的往往是子女和社区网格员，接收结论的才是老人

第三条决定了整个产品的形态：**手机端只做入口，不做大脑。**

## 结构

```
server.py            HTTP 服务：文字/图片核查、健康检查、静态页面
ocr.py               图片转文字：华为云 OCR / tesseract / mock 三种模式
skill_ocr.py         独立的 OCR Skill 服务（供 AgentArts 编排）
llm.py               本地模型封装（可选，不可用时退化为纯规则）
mobile.html          手机版页面（拍照 / 说话 / 看结论 / 转发）
index.html           桌面版页面（适合社区网格员批量核查）
kb_elderly.json      银龄子集 3,288 条（导入平台用这一份）
tools/               数据流水线：回抓、清洗、切分、测试集、召回评估
docs/                方案书、编排图、交接说明、任务单
tests/               召回测试集与报告
```

## 快速开始

```bash
python server.py          # 默认 8765
# 浏览器打开 http://127.0.0.1:8765/m
```

不需要安装任何依赖，纯标准库运行。

可选：配置华为云 OCR（不配则自动退化为演示模式，界面会明确标注）

```powershell
$env:HUAWEI_AK="..."; $env:HUAWEI_SK="..."; $env:HUAWEI_PROJECT_ID="..."
```

## 数据流水线

> 原始语料 `kb.json`（11 MB，20,122 条）不入库——它来自第三方辟谣平台的转载内容，
> 放进公开仓库不合适。仓库里保留的是已筛好的 `kb_elderly.json`；需要重建时跑下面的脚本。

```bash
python tools/refetch_official.py      # 回抓官方正文
python tools/filter_elderly.py        # 生成银龄子集
python tools/prep_kb.py kb_elderly.json   # 生成平台导入包
python tools/gen_testset.py           # 生成 20 条召回测试题
python tools/recall_test.py           # 跑召回基线
```

## 边界

- 不做图片鉴伪。公文、票据、P 图取证属于鉴伪业务，本项目不提供该能力
- 不替代官方发布。政策类内容一律提示"以官方最新发布为准"
- 不提供医疗建议
- 原图仅在内存中处理，不落盘；返回前对身份证号、银行卡号、手机号、验证码打码
