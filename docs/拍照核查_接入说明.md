# 拍照核查 · 接入说明

> 对应赛题二「基于华为云 AgentArts 智能体开发平台的 Agent 设计和应用」。
> 本条功能把「拍照/截图」作为老人最容易用的入口，接进已有的文字核查链路。

## 1. 做了什么，没做什么

**做**：图片 → 文字（OCR）→ 复用现有核查链路 → 返回同一张核查卡片。

**不做**：不判断"这张图片是真是假"。
公文真伪、票据真伪、P 图取证属于鉴伪业务，本项目既无资质也不该背书。
答辩时这句话要主动讲，它是边界，不是短板。

老人说"拍照辨真伪"，真实需求是**"别让我打字"**，OCR 正好解决这一点。

## 2. 在架构里的位置

编排图（`docs/银龄核查_Agent编排图.png`）里的 `ocr_extract` Skill：

```
拍照/截图 → [ocr_extract] → 文字 → ① 意图与主张 Agent → ② 核查 Agent → ③ 转述 Agent → 卡片
```

OCR 只负责"把图片变成字"，不参与判断，因此它可以独立替换、独立评估。

## 3. 三种模式（自动选择）

| provider | 触发条件 | 用途 |
|---|---|---|
| `huaweicloud` | 已配置 AK/SK/PROJECT_ID | **比赛正式形态**，华为云通用文字识别 |
| `tesseract` | 本机装了 tesseract | 断网/没凭据时的离线兜底 |
| `mock` | 以上都没有 | 只用于界面联调，前端会明确标注"演示模式" |

强制指定：`OCR_PROVIDER=mock`（或 `huaweicloud` / `tesseract`）。

## 4. 开通华为云 OCR（五步）

1. 注册华为云并完成**实名认证**（学生认证可选）。
2. 控制台搜索「文字识别 OCR」→ 开通服务（有免费额度）。
3. 右上角「我的凭证」→ API 凭证，新建 **Access Key**，记下 AK / SK。
4. 同一页面复制**项目 ID**（Project ID），并确认地域，例如 `cn-north-4`。
5. 设环境变量后启动服务（见下）。

## 5. 启动与自测

PowerShell（当前窗口有效）：

```powershell
$env:HUAWEI_AK="你的AK"
$env:HUAWEI_SK="你的SK"
$env:HUAWEI_PROJECT_ID="你的项目ID"
$env:HUAWEI_REGION="cn-north-4"

python -c "import ocr, json; print(json.dumps(ocr.status(), ensure_ascii=False, indent=2))"
python server.py
```

自测接口：

```powershell
curl.exe -s http://127.0.0.1:8765/api/health
```

返回里 `ocr.provider` 应该是 `huaweicloud`。若仍是 `mock`，说明凭据没读到。

单独测 OCR 模块：

```powershell
python ocr.py
```

## 6. 前端行为

- 输入框左侧新增 **📷** 按钮，点开可选「拍照」或「相册/截图」。
- 图片在前端压到最长边 1600px、JPEG 0.82 再上传，减少等待与流量。
- 识别出的文字会**回填到输入框**，老人可以改错字后点「核查」重查。
- 识别失败（没认出字）会给出可操作提示，而不是一句"失败"。
- `mock` 模式下页面顶部会挂一条黄色提示，避免现场误演示。

## 7. 隐私与合规（答辩必讲）

1. **原图不落盘**：只在内存里过一遍，用完即删，不写日志、不入库。
2. **不传给第三方**：华为云 OCR 是同一朵云内的调用，不经过任何第三方服务。
3. **返回前打码**：身份证号、银行卡号、手机号、验证码在回显前替换为 `****`，
   见 `ocr.mask_sensitive()`。老人拍照时很容易拍到这些。

## 8. 已知限制

- **华为云分支尚未联调**：代码按官方 AK/SK 签名规范（SDK-HMAC-SHA256）实现，
  但没有凭据无法验证。拿到 AK/SK 后请先跑 `python ocr.py` 确认。
- `tesseract` 需要安装中文语言包（`chi_sim`），否则只认英文。
- 单张图片上限 8 MB（服务端），前端已压缩，正常在 200 KB 以内。
- 一次请求耗时：华为云 0.5–2 秒，tesseract 1–3 秒（视 CPU）。

## 9. 接入 AgentArts

`skill_ocr.py` 把这一步单独暴露成 HTTP 能力，方便在平台上包装成插件 / MCP 工具：

```powershell
python skill_ocr.py        # 默认 8790
```

- `GET /` 返回接口 schema（可直接贴进平台文档）
- `GET /health` 返回当前 provider
- `POST /ocr_extract` 入参 `{"image_base64": "..."}`，出参 `{"text": "...", "lines": [...], "provider": "...", "ms": 812}`

在 AgentArts 里把「② 核查 Agent」之前的预处理步骤挂上这个工具即可，主服务无需改动。
